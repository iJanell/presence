# presence

Картинки для статуса Discord программы HvH Presence Studio (активность «CS2 | HvH»).
Discord берёт их по прямым ссылкам `https://raw.githubusercontent.com/iJanell/presence/main/art/<имя>.png`.

| Файл | Когда показывается |
|---|---|
| `art/cs2_lobby.png` | в лобби |
| `art/cs2_afk.png` | AFK |
| `art/cs2_afk_minimal.png` | AFK (минимальный стиль) |
| `art/cs2_fallback.png` | в матче, если для карты нет своей картинки |

Арт карт: `art/map_<карта>.png` (квадрат 1024×1024). Сейчас есть: ancient, anubis, baggage, botz, boulder, cache, debris, dust, dust2, eldorado, fachwerk, inferno, italy, mirage, nuke, office, overpass, pool_day, poseidon, shelter, shoots, train, vertigo.
Новую карту можно добавить сюда же и вписать её в программе: Activity & Art → «Карты с артом в папке».
