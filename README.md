# presence

Картинки для статуса Discord программы HvH Presence Studio (активность «CS2 | HvH»).
Discord берёт их по прямым ссылкам `https://raw.githubusercontent.com/iJanell/presence/main/art/<имя>.png`.

| Файл | Когда показывается |
|---|---|
| `art/cs2_lobby.png` | в лобби |
| `art/cs2_afk.png` | AFK |
| `art/cs2_afk_minimal.png` | AFK (минимальный стиль) |
| `art/cs2_fallback.png` | в матче, если для карты нет своей картинки |

Чтобы добавить арт карты, положи `art/map_<карта>.png` (например `art/map_mirage.png`, квадрат 1024×1024).
Картинки нарисованы программой (оригинальная композиция), это не файлы CS2.
